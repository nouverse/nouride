**0.8.23 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

On Docker, check your configuration with the new image before you switch:
`docker run --rm -v ./nouride:/app/.nouride ghcr.io/nouverse/nouride:0.8.23 nouride config check`, with the volume your
compose file mounts.

### The knowledge base

- **A document is found in any language by its title.** An agent that keeps a document gives it an English title that
  says what it is, with the document's own terms, kept beside the file's name, which does not change. An English search
  now finds a document written in another language even where search by meaning is not set up; before, it found
  nothing there. You can set a document's title on its row on the dashboard, in any language, or with
  `nouride knowledge title`.
- **The newest document is at the top.** A collection's documents are listed newest first, each saying when it was
  added. A file just added used to land wherever its name fell in the list.
- **A file added again under another name shows that name.** The same PDF added a second time as `SKT (2).pdf` was
  listed, and found, under the name it had the first time.
- **The memory graph joins conversations to documents.** With Documents on, a conversation has a line to each document
  it opened, and a document to each tag its frontmatter gives it, one dot with the conversations' tag of the same name.
- **The chat a waiting document came from hears the answer.** A document an agent kept into a collection open to more
  people waits for an admin; once they approve or decline it, that chat gets a line saying so, and the agent knows too,
  so it no longer says the document still waits.

### The dashboard

- **A refused setting says what to fix.** A save turned down for one field now names it, as the page does: "Nothing
  was saved. Check the address, and try again." It used to say "Check what you entered", and left you to guess which
  field.
- **Groups and Secrets have a search box,** as Missions and Jobs do: a room by its name, its chat app, who talks there
  or its agents; a secret by its name, what uses it, or its details.
- **An agent's files open in Preview,** with Edit one click away. Both are one height that scrolls inside, so
  switching no longer moves the page.
- **A mission told something on its page says which button moves it on,** "Continue lets it go on", where it named
  the chat's command.
- **The People page reads in everyday words.**

### The command line

- **A typo gets a suggestion.** `nouride missions` answers "Did you mean `nouride mission`?", and `nouride jobs lst`
  "Did you mean `nouride jobs list`?". It still exits 2.

### The bundled LLM gateway

- **A request goes to an Antigravity account that has the model.** Google moves accounts to a new model generation one
  by one, and an account asked for a model it does not have answered "no longer available" as if that were the reply:
  a Claude 5.5 request on an account still on 4.6, or the other way round. Each account is now offered only the models
  Google lists for it, and a model no account has is refused with an error that names it.
