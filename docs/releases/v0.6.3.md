### Install skills other people wrote

Your agents no longer have to learn every procedure from scratch. Skills written to the open [Agent Skills](https://agentskills.io) format can now be installed from public hubs:

- **GitHub:** any repository or folder with a `SKILL.md`.
- **[skills.sh](https://skills.sh):** Vercel's skills directory, which includes Anthropic's and OpenAI's skills.
- **[ClawHub](https://clawhub.ai):** shows its security scan for each skill, and refuses one it marks as malicious.
- **Any site that publishes a `/.well-known/skills/` index**, like agentskills.io.

Three ways to use it:

- **From the dashboard.** The Skills page has a new **Explore** tab. You can search every hub at once and install with one click, or paste a repository or URL.
- **From your agents.** Ask "find me a skill for spreadsheets" and the agent searches the hubs and queues what it finds. Agents now look there before writing a skill from scratch.
- **From the terminal.** Use `nouride skills search` and `nouride skills install`.

Every install is adjusted to Nouride automatically:

- The skill's frontmatter is converted to Nouride's format.
- The tools it declares become the tools Nouride agents have.
- The software it needs is detected from its scripts.

**Nothing is installed until you approve it.** Each skill waits on the **Pending** tab with where it came from and what was changed. Approved skills remember their exact source.

### A tidier dashboard

- **Long lists scroll inside their own cards** instead of stretching the page. This covers Skills, Secrets, People, Users, Schedule and every Memory tab.
- **The skills list and pending queue each have a search box.**
- **Overview** starts with today's token usage: input, output, and how much was cached. It is collapsed until you open it, and the default agent is marked with a crown.
- **Chat:**
  - The working card shows the agent's reasoning first, then its tool calls, which scroll in their own box.
  - Times are shown in whole seconds.
  - Background jobs started in a new conversation show up while the agent is still working.

### Fixes

- **`nouride update` works on newer Ubuntu releases** where it used to fail with "Function not implemented".
- **Every scheduled job is saved with an agent to run it.** A job an agent scheduled for itself could be saved without one and fail when it came due. Now:
  - A job an agent schedules for itself is saved under that agent.
  - A job without an agent is refused when it is created.
  - `nouride cron update <id> --agent <id>` repairs one created earlier.
- **A new skill can no longer silently replace a built-in skill** with the same name.

### Upgrading

- **Docker:** `docker compose pull && docker compose up -d`
- **Binary:** `nouride update`. If an earlier update failed with "Function not implemented", run the install script once: `curl -fsSL get.nouride.com/install.sh | sudo sh`.
