**0.8.37 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

On Docker, check your configuration with the new image before you switch:
`docker run --rm -v ./nouride:/app/.nouride ghcr.io/nouverse/nouride:0.8.37 nouride config check`, with the volume your
compose file mounts.

### The log says what made a conversation cost more

A model's provider keeps the front of a conversation, so the next request pays a fraction for what it has read
before. That only holds while the front stays the same: when something in it changes, everything after it is paid
for in full again, the whole conversation with it. Nouride knew when that had happened and not why.

- **When a part of what is sent in front of a conversation changed since its last request**, while the provider
  would still have had it, one line in the log says which parts: the tools, the model, or a section of the prompt
  by its name (the agent's memory file, what it knows about the people in the chat, its skills), with how much
  conversation is written again. Names and a size, never what a part holds. An admin finds the lines under
  **System**, **Logs**, by searching for `cached prefix`.

Nothing an agent reads or does changes in this release. What the lines show on a real install decides what is moved
or held still next.

### Before you upgrade

Nothing to do first, and nothing is different after it but the new lines in the log.
