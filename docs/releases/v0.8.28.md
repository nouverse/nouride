**0.8.28 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

On Docker, check your configuration with the new image before you switch:
`docker run --rm -v ./nouride:/app/.nouride ghcr.io/nouverse/nouride:0.8.28 nouride config check`, with the volume your
compose file mounts.

### One edition: Router is part of Community

- **Every Community install now carries the Nougate LLM gateway, switched off until you ask for it.** Setup offers
  **Use Nougate** at its provider step: choose it and the gateway starts at once, without a restart; skip it and it
  stays off and costs next to nothing. Later, **Settings → LLM Gateway** turns it on, or off (Nouride restarts once
  nothing is running).
- **A Router install moves to Community by its own update, with Nougate kept on.** Until 0.9 every release is also
  published under Router's old names, so `nouride update` and the old install command keep working. If you run the
  `nouride-router` container image, it keeps updating too, and its dashboard says to switch your compose file to
  `ghcr.io/nouverse/nouride`:
  [coming from nouride-router](https://nouride.com/en/docs/deployment/docker/#coming-from-nouride-router).

### New

- **Nougate learns each account's models from the account itself.** Codex, Claude Code, Copilot, Kiro and Antigravity
  are asked which models they serve when Nougate starts, when an account is added, and every six hours, so a new model
  shows up in your agents' model list without an update (GPT-6 Luna on Codex, for one). The last list is kept, so a
  restart or an outage does not empty it, and an agent set to a model the list does not show is still sent there: the
  provider decides.
- **Exa as a web search service**, beside Brave and SearXNG: pick it on the **Web Search** page and paste its key.
- **A model field opens its whole list from the arrow at its end.** Before, a field that already held a model showed
  only that model until you deleted its name.
- **The mascot's look for the Office:** a tuxedo coat, a helmet and photochromic glasses join the look words, and a
  new Nourider starts dressed as the mascot.

### Changes

- **Helpers an agent waits for move to the background after 45 seconds.** Work handed to a helper without
  `background` used to hold the chat until it was done, eight minutes once; now the agent waits 45 seconds, and a
  helper still working carries on in the background and reports when it finishes. Asking another agent does the same,
  after 45 seconds instead of a minute.
- **LLM Gateway sits above Models in Settings.**
- **Copilot no longer offers GPT-5.6 and GPT-6.** Copilot serves them only on a connection Nougate does not use yet,
  so picking one failed every time; reach them through Codex.

### Fixes

- **A reply that streams for more than two minutes is no longer cut off.** The two-minute limit was meant for a
  provider that never answers, and it also ended long answers that were arriving fine.
- **A long piece of work that writes many files no longer fails near its end** for want of room: the text of files it
  wrote earlier in the same turn is set aside once the conversation fills, as earlier tool output already was.
- **Stopping a turn frees the chat even when a tool does not stop.** A tool stuck on a dead connection could hold the
  chat until Nouride restarted; now the turn ends a few seconds after you stop it.
- **A provider's answer cut off before any of it arrived is asked again once** on the same model, before the next
  model in the agent's list.
- **"I'll try again in a few minutes" survives a restart.** A turn that ended on a provider error and promised a retry
  is retried after Nouride starts again, once.
- **A backup search service uses its own key.** With Exa or SearXNG first and Brave as the backup, Brave was sent the
  first service's key and refused every search; a backup with no key of its own is now skipped, and `config check`
  says so. Search errors say what they mean: a key not accepted, no credit left, too many searches.
