**0.8.19 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

On Docker, check your configuration with the new image before you switch:
`docker run --rm -v ./nouride:/app/.nouride ghcr.io/nouverse/nouride:0.8.19 nouride config check`, with the volume your
compose file mounts.

### Dashboard

- **Every page in everyday words.** The dashboard says what something means for you and what you can do there, without
  commands, file names or terms only the people who built it use. What matters to whoever runs the server is still
  there, under Details.
- **"Ask Nouva to set it up."** Where something is missing, such as Claude Code or Codex for a coding agent, a button
  opens the chat with your orchestrator with the request already written; you read it and send it, and nothing is
  installed without your yes.
- **The Secrets page shows what each secret is**: fields of your own beside a secret, such as its site, its account
  or what it is for, added and changed without touching the value. An agent fills them in when it saves a secret you
  sent it.
- **The MCP page is now Connectors**, in the menu and on each agent's page.

### LLM Gateway (router and Pro)

- **A conversation stays on the account that answered it.** With more than one Claude Code or Codex account, the
  gateway sent each request of a conversation to the next account, and each account cached the conversation again. It
  now goes back to the account that answered it last, for as long as that account can answer.
