### Attachments

- **A picture is no longer written over by the next one.** A file was named by its place in its message, so a file with
  no name of its own — every WhatsApp photo, every voice note, a Telegram photo the same size as another — took the
  same name as the one before it that day, and replaced it. Every earlier picture in a conversation then showed the
  newest: answering a quiz sent one photo at a time, the agent saw the same question in each, and took back answers
  that had been right. A file is named for when it came now, and none replaces another. Pictures and voice notes
  already written over are not recoverable.
- **Photos sent a moment apart are each filed under their own message.** A phone sending several photos at once makes
  one message of them, and every photo in it was filed under the last one — so a reply to the second photo, or the
  agent opening it again, brought up the first, and the first was handed to the model a second time as an earlier
  picture.
- **Each picture says when it was sent, and whether it came with the message being answered.** The model reads a line
  in front of every picture it is sent — "New picture, sent at 13:13 with the message you are answering", or "Earlier
  picture, sent at 13:08 — not part of the message you are answering" — in the daemon's time zone, so the photo being
  asked about is not mistaken for one before it.

### Before you upgrade

- Nothing to change: no migration, and the configuration is read as it is.
- **Docker:** `docker compose pull && docker compose up -d`. Check the configuration with the new image first: `docker run --rm -v ./.nouride:/app/.nouride ghcr.io/nouverse/nouride:0.7.29 nouride config check`.
