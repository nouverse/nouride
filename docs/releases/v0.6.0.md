### Memory, rebuilt

Agents now remember you across conversations: what you talked about, what you like, and what is coming up. [How memory works →](https://nouride.com/docs/architecture/memory)

- **Every conversation becomes a memory.** Once a night, each chat is filed as a short summary with tags, kept as a Markdown file you can open in Obsidian. Agents see the latest summaries in every conversation and can search the rest.
- **Your agent learns about you.** With learning on, what you tell an agent — what you use, prefer, plan — is kept in your profile and remembered by every agent that talks to you. What you say in private stays in your private chats.
- **Dates and follow-ups.** Plans with an end date stop being brought up once they are over; birthdays and appointments come up the week before; "remind me to…" is kept as a follow-up until it is done.
- **Search that works without extra models.** Keyword search is built in, and understands Indonesian word forms (`liburan` finds `berlibur`). Semantic search is optional — the Memory settings show how to add an embedding model from Ollama, OpenAI or Gemini.
- **Forget, undo, and a record of every change** on the Memory page. The memory folder is backed up daily beside the database.

### Voice notes and videos

- **Agents listen to voice notes.** When the agent's model can hear, a voice note goes to it as sound — tone, names and all — not as a rough transcript. When it cannot, the agent says so honestly instead of guessing, and you can set up a transcription service as a fallback.
- **Agents watch videos.** A video you send is read as a handful of frames plus its sound, so the agent can tell you what happens in it.

### New built-in skills

- **Browser automation** — the agent drives a real browser to log in, click through and fill in sites, asks before anything that cannot be undone, and can turn a flow that works into a script that runs again on its own.
- **Motion graphics** — short videos made from code with Remotion. The agent checks first whether your machine can render them, and uses another of your devices when it cannot.
- **Video summaries and clips** (nouclip) — summarize a video or a YouTube link, or cut it into short vertical clips with word-by-word subtitles. YouTube's own captions are used when available, so it is fast and light.

[All built-in skills →](https://nouride.com/docs/manual/skills#built-in)

### Faster, sturdier tool use

- **Fewer steps, quicker answers.** Agents chain the commands they already know into one step instead of running them one by one, and search several queries or open several pages at once.
- **Big outputs no longer get in the way.** A command that prints a lot — a long build, a big log — is saved to a file the agent can read back as needed, instead of flooding the conversation. Long builds are no longer cut off partway.
- **Commands that leave something running return right away**, instead of hanging until they time out.
- **Secrets stay hidden.** A password or key an agent is given is masked wherever it would show up in a tool's output, and one agent cannot read another's job logs.

### Agents

- **Presets for a new agent:** Pilot (everything), Researcher, Assistant, Developer, or Custom. Tools can be switched later on the agent's new **Settings** tab.
- **New agents ask only before something risky** — deletes, system changes, credentials — for everyone who talks to them.
- **Make any agent the default**, from its page. The default is listed first everywhere.
- **Accept new senders per agent**, or follow the default.
- **More built-in skills:** reach other devices on your network or through Tailscale (with setup guides for Windows, macOS, Android, cameras and more), and share a public preview link of something an agent built.
- **System packages, if you want them.** Install with `--allow-packages` and agents can install, remove and upgrade packages from your system's own repositories — asking you before every change, and never removing what keeps the box reachable. Off otherwise; agents install into their own folder as before.
- **Servers stay up and the agent carries on.** A dev server or tunnel an agent starts is a background job you can see and stop, and the agent keeps working instead of stopping to wait for it.
- **No more silent waits on long jobs.** When a build or download runs a long time without news, the agent tells you which job it is, how long it has been running, and that it is still going — after 5 minutes, then 10, 20, 40… It never stops the job, and servers are left alone. Change the wait in **Settings**, for all agents or just one.

### Setup and dashboard

- The setup wizard ends with a short memory step: remember conversations, learn about you, shared knowledge — or skip.
- One tab style across the dashboard; the model picker's list no longer hides behind other cards; signing out asks first.
- The first-login message names an address other devices can open when the dashboard listens on the network.

### Upgrading

- **Docker:** `docker compose pull && docker compose up -d`
- **Binary:** `nouride update`

Your data carries over. Worth knowing ([full upgrade notes →](https://nouride.com/docs/deployment/updating#from-05-to-06)):

- **Memory's nightly pass is off after an upgrade.** Turn it on under **Memory → Settings** (or `nouride memory set pass on`), and choose on the **People** tab whether agents learn about each person.
- **The agents' home directory moved into `.nouride/home`.** ssh keys and config, and anything else an agent set up in its home, are copied across on the first start — the old copy is left in place. In Docker this is inside the volume now, so it survives a container being recreated.
- `[session_memory]` in `config.toml` is no longer used; it is reported at start and can be removed. Conversations still in the daemon's history are filed by the first nightly pass; older saved transcripts can be brought in with `nouride memory backfill <folder>`.
