# Screenshots and video

Every slot the docs point at starts as a **placeholder**, generated by
`bun run apps/site/scripts/make-placeholders.ts`, which says on its own face what belongs there and at
what size. Most are real screenshots now; the `.svg` files left are the slots still waiting.

## Replacing one

Drop a real asset in with the **same stem** and delete the `.svg`:

```
dashboard-overview.svg   →   dashboard-overview.png
demo-poster.svg          →   demo-poster.png  +  demo.mp4
```

Then update the reference in the page that uses it — the extension is written out in the Markdown,
so `![…](/media/dashboard-overview.svg)` becomes `…overview.png`. The generator skips any slot that
already has a `.png`, `.jpg`, `.webp`, `.gif`, `.mp4` or `.webm`, so re-running it will not clobber
your work.

## Which ones the landing page uses

`dashboard-office` only, in the Office chapter, drawn at half the page's width. It is the one screenshot
a visitor sees before the docs, so it is worth replacing first; the rest are referenced from the manual,
where a reader already knows what they are looking at.

## Adding a slot

Add an entry to `SLOTS` in `apps/site/scripts/make-placeholders.ts` and re-run it. Keep that list and
the pages that reference it in step — a slot nobody points at is a screenshot nobody takes.

## What to capture

Use a **fresh install with fake data** where you can. These pages are public: people's names, chat
IDs, phone numbers, usernames, host names and spend figures from a real deployment do not belong in
them. The first-run, chat, approval, CLI and connection shots come from a throwaway install in a
temporary directory, signed in as `alex`, with a small stand-in for a local model on
`localhost:11434` — enough to pass the wizard's connection test and run one tool call. A page that
needs real history — the memory graph does — may come from a live box only when its names are
replaced before the page renders (rewrite the `/api/control` answers, not the pixels, or a canvas
label slips through) and any line of private text is blurred: a job's prompt, a memory's summary.
Shoot at 1280×800 with a device scale of 2, and take both light and dark if the page shows the two
side by side.

## The demo video

The landing page has a slot for one, and it currently shows `demo-poster.svg` as a still — deliberately,
so that nothing on the site links to a file that does not exist yet.

To turn it into a player: drop your recording in as `demo.mp4`, replace `demo-poster.svg` with a frame
from it (`demo-poster.png`), then swap the image for the `<video>` snippet written out in the comment
directly above it in `src/content/docs/{en,id}/index.mdx`.

Under 60 seconds, no narration needed, 1600×900 or larger.
