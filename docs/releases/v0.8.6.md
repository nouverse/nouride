**0.8.6 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

### Agents answered by Claude Code or Codex

- **"I'll tell you when it's done" now comes.** Claude Code goes on by itself when a command it left running in the
  background ends, a build or the tests, and says what came of it. Nouride dropped that, so the news never reached
  the chat. It now arrives as the agent's message, the way a background job's result does. If you write first, it comes
  before the answer to your message.
- **A command it left running in the background is no longer stopped with it.** The CLI was stopped five minutes after
  its last message, and the command with it. It now stays up while one runs, and an update or a restart waits for that
  command as it waits for a background job, unless you ask for it now. If Nouride is stopped at once or crashes while
  one runs, the agent says so after the restart, as it does for a background job.

### Fixed

- **A bot or a server an agent starts with `&` keeps running.** On a Linux install where each agent is its own user,
  one that printed to its command's output stopped about two seconds after the command ended, so an agent that started
  `python3 bot.py &` found it dead and tried again and again. It now runs until it ends.
- **An agent whose `pkill -f` stops its own command is told so.** A pattern that is also in the command's own line
  stops the shell running it, which came back as exit code 143 and no output; agents took it for their output being
  cut, and said so. The result now says what happened and how to match around it.
- An agent made from a chat, or from the form, whose soul began with a heading of its own got `# SOUL` twice at the
  top of its `SOUL.md`. It keeps the heading it brought.
