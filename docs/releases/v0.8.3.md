**0.8.3 updates from 0.8.0, 0.8.1 or 0.8.2.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

### Nouride Pro on a Mac

Nouride Pro now runs on a Mac with Apple Silicon (M1 and later), as it does on a Linux server, and takes its updates
from Nouverse at night like a Nouride Box. Intel Macs are not supported. It runs while you are logged in; to keep a Mac
serving around the clock, see [Install](https://nouride.com/en/docs/start/install/).

### Fixed

- **On a Mac, an update that does not start is undone.** Nouride goes back to the version before it after three tries,
  where it used to be restarted every ten seconds for good. An install already running gets this the next time its
  installer runs.
