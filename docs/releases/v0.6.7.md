### Memory search is faster

Memory search looked up a long word by reading the whole keyword index, once for every word in the question. It now goes straight to the part of the index that matches. On a box with 895 remembered conversations, at the 95th percentile:

- **Finding and ranking keyword matches:** 150 ms → 10 ms.
- **A whole keyword search:** 161 ms → 24 ms.

The results are exactly the same. On that box, 11,004 word beginnings found identical matches the old way and the new way.

### Updating

- **`nouride update --start` is the whole command at a terminal.** It used to print its usage and do nothing unless you also passed `--no-then`. Agents still pass `--then`, so the conversation that asked for the update hears back once the new version is up.
- **A clearer message after a rolled-back update.** If an update changes the database and is then rolled back, the older version now says that a newer Nouride upgraded the database, and points to the snapshot from before the upgrade: `nouride db list`, then `nouride db restore <file>`. `nouride db adopt` refuses this case instead of recording a schema the older version has never seen.

### Upgrading

- **Docker:** `docker compose pull && docker compose up -d`
- **Binary:** `nouride update --start --no-then`. The `--no-then` is for 0.6.6, which still asks for it; from 0.6.7 on, `nouride update --start` is enough.
