**0.8.4 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

### Fixed

- **A picture sent as a file is a picture.** A screenshot sent uncompressed — Send as file in Telegram Desktop — reached
  the agent as a document it opened with its tools, step by step. It is in front of the model now, as a photo is. A
  file whose content is a PNG, JPEG, GIF or WebP counts as one on every channel, whatever it was labelled.
- **A picture the model cannot take no longer fails the reply.** A HEIC from an iPhone, a BMP or an animated sticker was
  sent to the model, which refused the whole request. The agent is told which format it was, and can ask for a PNG or
  a JPEG.
- **A Codex agent in a mission answers as itself.** In a mission's repository, an agent answered by Codex worked without
  its name, its voice and its memory. Its persona reaches it in any folder now.
- **On a Mac, the installer's last lines** told you to open an SSH tunnel to the Mac itself. They say to open the
  dashboard there.

### Nouride Pro

- Nouride Pro runs on an Intel Mac too, with macOS 13 or later, installed the same way as on Apple Silicon.
- When a Pro licence no longer takes new releases, `nouride update --check` and the dashboard's Update page say so —
  Nouride keeps working, and critical fixes still come — rather than "up to date".
