### Conversations stay cached between messages

The system prompt used to end with the current time, down to the millisecond. A provider's prompt cache only reuses text up to the first thing that changed, so every new message re-read the whole conversation at full price. Only the tool steps inside one reply were cached.

- **The system prompt now carries only today's date.**
- **The exact time is added to the message being answered.** It is sent with the message but not saved, like the other notes added to a turn, so your agent still knows what time it is.
- **The conversation before your last message is now reused from the cache.** This matters most on providers whose cache lasts a few minutes, like Anthropic, and in fast back-and-forth chats.

### Upgrading

- **Docker:** `docker compose pull && docker compose up -d`
- **Binary:** `nouride update`
