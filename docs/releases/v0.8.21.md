**0.8.21 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

On Docker, check your configuration with the new image before you switch:
`docker run --rm -v ./nouride:/app/.nouride ghcr.io/nouverse/nouride:0.8.21 nouride config check`, with the volume your
compose file mounts.

### Where Nouride lives

- **The source is on GitHub,** at [github.com/nouverse/nouride](https://github.com/nouverse/nouride), the repository the
  releases were already on: the downloads, the images and the issues are where they were, and installs update as before.
- **The built-in skills and agent templates** are part of it, in `content/`, under the MIT licence: change the agents
  and skills you run as you like.

### Fixes

- **A file an agent may not write is said so.** Where each agent's commands run as its own user, a file it was not
  allowed to write came back as "broken pipe" now and then, instead of the reason.
