**0.8.30 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

On Docker, check your configuration with the new image before you switch:
`docker run --rm -v ./nouride:/app/.nouride ghcr.io/nouverse/nouride:0.8.30 nouride config check`, with the volume your
compose file mounts.

### Agents that work together by default

- **An agent knows the machine it runs on.** Its cores and memory, and how many helpers and missions may run at once,
  are part of what every agent is told, with what is running right now. An agent on a small box no longer starts four
  builds at once because nothing told it the box was small.
- **Up to four helpers and four missions at once, lowered by the machine.** Where you set no number, both follow the
  machine: four on a box with the cores and memory for it, fewer on a small one (one on 2 GB, two on 4 GB). A number you
  set in the configuration or on the dashboard is kept. Before, it was two helpers on every machine, and missions by
  the number of agents.
- **One agent asks several others at once.** The orchestrator can hand a piece of work to three agents in one step:
  they work at the same time and their answers come back together. Before, it asked them one after another.
- **Agents are told when to work in parallel**: parts that do not depend on each other at once and in the background,
  parts that do in order, and heavy commands one after another on a small machine.

### New

- **After a long outage, an agent asks before it carries on.** A turn cut off by a restart is carried on by itself only
  if Nouride is back within 15 minutes. After a longer outage (a power cut, say) the chat used to hear nothing; now it is
  asked once, "I was cut off 1 hour ago while working on … Say "continue" and I will pick it up", with a **Continue**
  button on Telegram and Discord. Nothing is carried on by itself after that long.
- **The dashboard shows what is loading as its shape**, where a spinner stood: a page, a card, a chat. A list no longer
  shows "nothing here" for a moment before its content arrives. The cat is in more places: beside page titles, in empty
  lists, and a different one each time you open Home.

### Changes

- **Requests to OpenAI's and Anthropic's own APIs say which agent and conversation they are for**, so the provider's
  cache is reached more often and a long conversation costs less. What is sent is the agent's id and a code for the
  conversation that holds no name, phone number or chat id. Nouride adds the setting (`identify = true`) to a provider
  on those two addresses at the first start; set `identify = false` to keep it off.
- **Long turns keep the provider's cache.** When a long piece of work fills the conversation, old tool output is set
  aside in one go, where it was set aside a little on every step, which made the provider read the whole conversation
  again each time.

### Fixes

- **On a phone, the tab bar takes every tap.** With More open, the bar was covered by More's sheet, and for a moment
  after choosing a page a tap on a tab could open something else. On a phone, More lists Settings as one line; its pages
  are on the Settings page.
- **Deleting a second conversation works.** After one conversation was deleted, from History or from a chat's menu,
  Delete on the next one did nothing until the page was reloaded.
- **Every page has room under its last card**, on a phone and on a computer, so the tab bar or the window's edge no
  longer sits on the last line. On Home the Chat button no longer covers the last card.
- **A promise to try again survives a change of wording.** A turn that ended on a provider error and promised a retry
  is found after a restart by a mark on the turn, where it was found by the sentence it ended with.
- **A turn lost in a crash is not carried on hours later** by a second restart.
