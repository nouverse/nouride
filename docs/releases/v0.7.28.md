### Credentials

- **A search pattern is no longer taken for a credential file.** A command whose line held a pattern such as `grep -iE 'credential|\.env|\.key|token'` was read as printing a private key, so every `key: value` line it printed was masked — a commit message read in `git log` as `feat: $TMP_SECRET_…`. An agent checking its own commit that way took the commit for broken and rewrote it. A pattern no longer counts as a file name.
- **A command that makes a repository and commits in it runs.** `git worktree add … && cd <the new tree> && git commit`, or a commit in a directory from `mktemp -d`, failed whole with "Something went wrong": the check that keeps a credential file out of a commit ran git in a directory that did not exist yet. It now lets such a command run.
- **Masked output says that only the output is masked.** The note under a command whose output held credentials now says that nothing the command read, wrote or committed was changed, so an agent does not set out to repair what is not broken.

### Before you upgrade

- Nothing to change: no migration, and the configuration is read as it is.
- **Docker:** `docker compose pull && docker compose up -d`. Check the configuration with the new image first: `docker run --rm -v ./.nouride:/app/.nouride ghcr.io/nouverse/nouride:0.7.28 nouride config check`.
