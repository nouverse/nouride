**0.8.12 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

No database migration. The event protocol is 1.7: a retry row may say a model's fallback (below).

On Docker, check your configuration with the new image before you switch:
`docker run --rm -v ./nouride:/app/.nouride ghcr.io/nouverse/nouride:0.8.12 nouride config check`, with the volume your
compose file mounts.

### The dashboard on a phone

- **No zoom when you tap a field.** Every input, list and text box is 16 px on a phone, the size below which iPhone
  zooms in on it — the login page did. You can still pinch to zoom.
- **Type you can read.** Nothing is smaller than 12 px on a phone, and text that was set smaller there than on a
  computer is 14 px.
- **Room at the bottom of every page,** above the browser's toolbar and the home indicator. The last card sat flush
  against the edge. Below laptop width, a page scrolls as one page, not a list inside a card.
- **Nothing past the screen's edge.** The chat's suggestions, a long room name, and grids that grew wider than the
  screen pushed the page sideways. Copy and delete on a chat message show on a phone; they appeared only on hover.
- **System Logs read as blocks:** time and component on top, the message the whole width below, its fields under it
  when opened — the daemon log, the audit and the scheduler's runs. The message was a column three letters wide. Tab
  bars are one row that scrolls.
- **A mission's steps:** how the step went on top, the command the whole width below it, and a turn the whole width of
  its card. A Claude Code turn no longer shows "0 in / 0 out tokens" above its model calls' real figures.
- **A brief's long path** wraps inside its card, and **BRIEF.md** sits below the title on a phone; it ran over the
  button.
- **A skill draft's description** is the row's width on a phone, with Keep and delete under it; beside them it was a
  column a third of the screen wide. Inline code in a mission's result is at least 12 px there.
- Groups and Users are a card per row on a phone, as People is. Small buttons are at least 32 px tall.
- **The chat's message box lines up**, on a computer too: the attach and slash buttons sat a few pixels under the
  line of text, and the slash button was a leaning "/" — it is an icon like the paperclip now. The box says
  "Message Nouva…"; Enter and Shift+Enter are said under it.

### Agents in a room

- **A tag of one agent by another reaches it whole.** Nouva's "@NexaNourideBot, go ahead" reached Nexa as
  "NourideBot, go ahead": the agent's name was cut off the front of its bot's handle.
- **A scheduled post in a group hands its tag over after a restart.** Until someone wrote in the group again, a
  scheduled turn there was taken for a one-to-one chat, and an agent's tag of another agent's bot was posted and never
  reached it. A background job's report, an approval answered late and a turn resumed after a restart were taken the
  same way. A group the daemon has a record of is now known as one from the start.
- **An agent with no bot of its own reaches the agent whose bot it speaks through** when it tags that bot's handle.
  The tag was posted, and nobody was handed it.
- **On Discord, an agent whose bot cannot read a channel is not offered as one to tag there.** Each agent's bot is
  asked whether it may view the channel; one that may not is named apart — "not in this chat" — so the agent can say
  why. A tag of it anyway is followed by one line saying it reaches nobody and what to do. In a channel only one
  agent's bot could view, its tags of the others had gone nowhere, with nothing to say so.

### Quiet when there is nothing to say

- **An agent answered by Claude Code or Codex no longer sends a filler line** after a background job, an approval or
  a long job's check-in that needed no answer ("nothing new to report, now I'm waiting…"). Told to reply with nothing,
  the CLI asked its model again for something to say. Every agent is now told to reply with only ".", which is never
  sent.

### Missions

- **A mission sends the files made for you, never what checked the work.** Evidence, stills, test fixtures or an answer
  key are named in its report instead; its page says so every turn. A mission testing another agent had sent its
  answer key to the group that agent reads.
- **A question a mission asks with numbered options gets its buttons**, as one with A) to F) did; six answers are
  two rows of buttons on Discord, which refused six in one row and the question with them. **A reply in your own
  words answers it** — to the agent, in the chat — and the question now says so beside `/mission answer`.
- **A mission's files are checked when it says it is done.** A file that is not there, or a folder, is refused with
  the path it resolved to, and the agent names it again in the same turn. A video named with its folder twice had
  ended a mission with "Not sent as files".
- **A stopped mission no longer counts against its provider.** Each stop logged an error and added a failure to the
  provider's health, so health blamed a provider that was answering.
- **One stopped before any turn finished** reads "ended before a turn finished", not "0 turns ran" — and not "turn 0
  of 100" in `nouride mission show`, which now says a mission's turns as its page does; a draft dropped reads "ended
  before it started".
- **An answer from another agent that arrives in a mission's turn** goes into the work and the report. The mission was
  told to pass it on to the person, from a turn nobody reads.
- **A mission run by Claude Code or Codex is told the truth about its memory:** its session lasts the whole mission, so
  it remembers its earlier turns. Its page said every turn starts from the page.
- **A scheduled mission's brief is checked when the job is proposed**, as its goal is: in English, as briefs are. A
  run starts as the person who turned the job on, so nothing read it.
- **When the disk is low, ended missions' folders go early.** Under 1 GB free where missions work, an ended mission's
  own folder is removed an hour after it ended rather than a week, oldest first, and never over work nobody committed.
  On a box, sixteen ended missions' worktrees had held 1.9 GB.

### Usage and health

- **A stop that runs out of time says which step held it** in the log line it ends with.
- **A model's fallback is said properly.** When an agent's model failed and the next of its chain answered, the step
  was one the event contract did not describe, and the log warned of it. `retry` rows may now carry `reason: "fallback"`
  with `from` and `to`.
- **A coding CLI that reports only its total tokens** is recorded with that total as input, marked an estimate, not as
  0 in and 0 out.
- **An agent sees every picture it opens.** A request carried the newest four; an agent checking a video's stills lost
  each set as it opened the next, read the same files again until its turn was ended, or decided they had never
  reached it. The size a request may carry is the only limit left.
- **A helper stopped for repeating itself says it did not finish.** When the same call kept giving the same answer
  and the turn was ended, the helper handed back "success" with a summary that began "Not finished", and the chat was
  told it was done.
- **Helpers & jobs, a page under Monitor.** Every helper, background command and asked agent, each opening to what it
  was asked, its steps as they happen, what it handed back and its own turn, with Stop while it runs. How long their
  output is kept is set there too.
- **Background job output and scheduler run history are kept 3 days by default**, not 14 (`[retention] job_log_days`,
  `[cron] run_retention_days`). An install that never set them sweeps older ones at its first boot on 0.8.12; set the
  keys to keep more.

### Built-in skills

- **The skills are their own public repository**, [nouride-builtin-contents](https://github.com/nouverse/nouride-builtin-contents),
  and each names its newest copy there: an install older than a skill reads what has moved on, and follows its own
  copy where the newer one asks for a tool it does not have.
- **diagrams**, new: architecture, a network at home, a flowchart or a process, drawn from a short list of boxes and
  arrows into a PNG and an SVG with Graphviz — little first, and looked at before it is sent. It counts the arrows
  that cross, and names the ones that run back against the flow — a reply, a notification — which drag a box to the
  far end under a long arc; such an arrow can be told not to pull.
- **home-assistant**, new: lights, climate, an air purifier, a vacuum, scenes and history through Home Assistant, found
  by the names people use for them; an unlock, a door or a gate opened, an alarm disarmed wait for a yes. A device
  Home Assistant does not have yet is one question, then found by what it announces on the network, then brought in
  with its integration — or reached without Home Assistant where it has a way.
- **homelab-ops**, new: one ranked health report for a server — disk, memory, services stuck restarting, journal
  errors, containers, certificates, backups, updates — locally or over ssh, and a daily check that speaks only when
  something is wrong.
- **mail-calendar**, new: mail over IMAP and SMTP and calendars over CalDAV or an ICS feed — a morning brief, search,
  replies in the same thread, events with their repeats. Nothing is sent before you see it.
- **research**, new: an answer from many sources, each claim cited to a page that was read; a ledger of sources checks
  that every citation has its source and every quote is the page's own words.
- **data-sheets**, new: a table profiled before anything is computed, a clean copy that keeps the original, totals
  reconciled, charts that are right by default, and a new workbook read back to check it. Numbers and money are
  written the way the reader's locale writes them, any locale and currency; a number that reads two ways is asked
  about, not guessed. A dashboard — number tiles and several charts on one picture — starts from a working example
  that prints every number it draws and checks that its totals agree.
- **slides**, new: an outline for a yes, then a deck rendered to PDF and a picture per slide, every slide measured and
  looked at before it is sent; PowerPoint too when asked. The PDF's pages are counted against the slides: a slide
  that ran onto a second page only in print looked right in every picture.
- **An agent no longer proposes changes to a skill that ships with Nouride.** Learning from a conversation, an
  agent drafted an "improves" for motion-graphics, which Skills offered with an Apply that could only refuse it — a
  built-in is changed where Nouride is written, and an upgrade would have replaced it. Nor to a skill a person wrote.
- **A file an agent writes no longer hides its build log.** A file written from the command line whose text named a
  credential file — a flyer saying "credentials" — made the daemon take the command for one printing credentials, and
  every `name: value` line it printed came back masked: a LaTeX build's warnings could not be read.
- **Credentials sent in the chat** are kept with `secret_save` in coding-agents, browser-automation and network-reach.
  They said a credential is never typed into the chat and named only the command line, which a Docker install or a
  phone does not have.
- **coding-agents** drafts long work as a mission, and inside a mission works in the mission's folder rather than a
  new worktree beside the repository.
- **nouride** updates through the `update` tool, and says which sign-in an agent may run itself.
- **document-authoring** looks at the pages of a PDF before it sends it: a clean build log had passed a document still
  carrying its template's title. After a fix it looks again: the PDF sent is the one looked at last. One command now
  compiles the PDF, names each problem by its line and renders the pages to look at — including a reference or a
  citation that did not resolve (`??` in the PDF), a figure too tall for the page and a type size the document class
  ignores, none of which the compiler printed.
- **motion-graphics** drafts a whole video as a mission with the storyboard in its brief, and writes its defect list
  down every round — each item "none" or what was seen — and sends that list with the video. Each round also looks at
  every scene a second after it starts, where something left from the scene before shows: the stills taken at a
  scene's end and the contact sheet fell either side of it. And what can be measured is measured: a check that ships
  with the skill outlines, on each still, text too small, text in the margin, a word alone on a last line, and text
  over a picture or over other text. Looking alone, an agent had read a too-small line on three rounds of stills and
  passed it. The frames are printed from the scene list and all taken every round: an agent's own pick had missed a
  caption that came in mid-scene.
- **share-preview** looks at the page before it sends the link — at a laptop's width and a phone's, through
  browser-automation, with the page's own errors — and checks that the public link answers. A link to a blank page or
  a script error went out as if it worked.
- **nouclip** is a third of its length: its procedure and every rule kept, the flag tables left to `nouclip --help`.
  It installs without piping a script into a shell, and takes its keys from the agent's credentials, not a file.
- **network-reach** names no address of its own for a model to copy. Asked "can you access my phone, my laptop, my
  CCTV, my air purifier?", an agent finds it and answers with the way in for that kind of device rather than "no"; away
  from home the way is Tailscale, and what cannot run it is reached through a machine at home that routes for it —
  never a port opened on the router. An iPhone is said plainly to have no way in, then the ways that work: a Shortcut
  that calls a webhook, Run Script over SSH, iCloud through a Mac. A camera's frame is taken with an FFmpeg that reads
  RTSP, installed where there is none.
- **motion-graphics** asks for your assets before looking for any, finds the rest only where a licence is stated, and
  cuts them to size with commands that run as written; every line it puts on screen names its source in the
  storyboard. A clean check frame keeps its top visible.
- **browser-automation** works as written on a Linux box, a Docker install and a Nouride Box. Its setup now writes the
  config that names the browser it installs: without it the tool looked for Google Chrome, and the first page an agent
  opened failed. The tool's folder is the agent's own private folder, by its full path — a saved login was kept where
  every agent could read it. The tool's version is pinned, its size is the one measured (about 280 MB), a page is read
  off its screenshot before an agent says what happened, and a flow kept as a script runs from its folder — on a
  schedule as a command, with no model. A page its own scripts build is read as Markdown in one command, and a bot
  check stops it with a screenshot for you rather than being fought. A flow kept as a script starts from a template
  that keeps a screenshot, the page and its errors when a step fails.
