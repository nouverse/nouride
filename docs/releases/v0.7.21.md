### MCP

- **Choose which of a server's tools each agent gets.** Every tool an MCP server offers went into every request of every agent it was on for — Notion's 65 tools are about 250 KB each time. Now **Tools** on the server's row in the agent's MCP tab opens a checklist of its tools, each with what it adds to a request, and `nouride mcp tools <server> --agent <id> --only <tool,…>` does the same from a shell (`--all` gives every tool back). A tool left out is not sent to the model, and a call to it is refused. Nothing changes until you choose: without a list an agent has all of a server's tools, as before. `nouride doctor`'s warning about a large server now says how, and `nouride mcp` lists the orchestrator first under each server.

### Updating

- **A bridge release.** Updating now also reads checksum files named `CHECKSUMS`, beside `SHA256SUMS` — `nouride update`, the dashboard and `install.sh` — so it keeps working with the releases after this one. **Nothing to do but keep updating.**

### Releases

- **Releases take fewer steps.** The public images' kits are made in the same step as their tarballs, not in a step of their own. Nothing changes in what is published or how you install it.
