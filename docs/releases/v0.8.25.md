**0.8.25 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

On Docker, check your configuration with the new image before you switch:
`docker run --rm -v ./nouride:/app/.nouride ghcr.io/nouverse/nouride:0.8.25 nouride config check`, with the volume your
compose file mounts.

Most of this release is Nouride's own code made tidier, so the features that come next are easier to build and to
check. Nothing you set up changes, and your agents answer as they did.

### Ask your orchestrator, from any page

- **An "Ask" button in the header of most pages** opens a chat with your orchestrator, with a request for that page
  already written: *Ask Nouva to create an agent* on Agents, *to set up a webhook* on Webhooks, *to schedule
  something* on Schedule, *to add a model* on Models, and the same on Skills, Connectors, Missions, Memory, People,
  Integrations and more. Fill in the gap and send it; nothing is sent until you do. It is shown to an admin or an
  operator, once an orchestrator is set.

### Chats

- **Deleting a chat or a room is in a "⋯" menu** at the end of the chat's top bar. The bin sat beside the other
  buttons, and on a phone it touched the notes button: one slip from a delete that cannot be undone. A room is deleted
  from the same menu, and the confirmation still names every agent whose conversation goes with it. The history list
  keeps its delete on each row.
- **A delete that fails says so**, where it said nothing.

### Models

- **Model tiers open from a button** beside Add Provider, in a window of their own. They sat as a panel between the
  page's tabs and your providers and pushed the list down.

### On a phone

- **A skill's row uses the screen's width:** its switches sit beside its name, and its description and the agents'
  switches run below. A long list of tools wraps inside its label instead of spilling over the description.
- **Home's "Everything is working"** and the version beside it no longer break in the middle of a line.
- **Under the tab bar,** the page no longer shows through the gap above the browser's own toolbar.
- **A secret's note is shown whole,** where it was cut short and the rest showed only under a mouse pointer.

### The website

- **The Android tab on nouride.com's install picker** shows Android's own mark, beside Linux, Mac and Docker.
