### Tools

- **`task_plan` is `plan`**, so that "task" can mean the task board 0.8.0 brings. The checklist works as it did; its argument is `steps`, and a call with the old `tasks` is still taken.
- **A pack that names `task_plan` keeps working** — in `[tools] enabled`, `approval_required` or `blocked` it is read as `plan`, with one line in the log each time the pack loads. Rename it when it suits you: 0.8.0 stops reading the old name, with the rest of the forms in the upgrade window.
- **A tool blocked by an old name stays blocked.** `blocked` is read through the same renames as `enabled` now; before, a pack that blocked `memory_recent` had `memory_search` back.

### Helpers in the background

- **A chat turn that runs long is reminded that a helper could have the rest.** Asked to check every link in the docs, an agent spent four minutes on it in the foreground while you waited, though it had been told that work like that goes to a helper in the background. Now, after eight calls or two minutes — once a turn — the agent is told so at that moment: hand what is left to one helper in the background and stay free for you, or finish it if it is nearly done. Only for an agent that may run helpers in the background.

### The dashboard

- **Blue, from the mascot.** The brand colour is the cat's own azure, lifted on dark and deepened on paper so every text on it reads at WCAG AA; the ink is navy, the surfaces a cool paper and a slate-blue mist. Green is only success now.

### Upgrading

- **Docker:** `docker compose pull && docker compose up -d`. Check the configuration with the new image first: `docker run --rm -v ./.nouride:/app/.nouride ghcr.io/nouverse/nouride:0.7.16 nouride config check`.
- **Binary:** `nouride update --start`.
- **Before you upgrade:** nothing to change. A pack that lists `task_plan` keeps it, as `plan`. There is no migration in this release.
