### Faster, richer web search without an API key

`web_search` without a Brave key or SearXNG used to ask DuckDuckGo, then the next source, one at a time and with no time limit, so a throttled source could hold a search for minutes. [How search works →](https://nouride.com/docs/architecture/tools)

- **About a second, not minutes.** Every free source is asked at once, each with a 6-second limit. The search returns shortly after the first general engine answers.
- **More places to look.** DuckDuckGo and Bing for the web, plus Google News, Wikipedia, Reddit, GitHub, Stack Overflow, npm, MDN, Hacker News and arXiv. Results are merged, duplicates removed, general results first.
- **The agent picks the sources.** A programming question can ask code sources, a research question can ask arXiv, and a question about today can put headlines first. Everyday questions don't get padded with repositories.
- **In the user's language.** News comes from the matching Google News edition (around 30 languages and regions), and Wikipedia in that language is searched beside the English one.
- **Junk is left out.** When an engine sends results that have nothing to do with the query instead of refusing, which Bing sometimes does, its answer is dropped.
- **A hung search API no longer holds the turn.** A configured Brave or SearXNG that doesn't answer in 10 seconds falls back to the free sources.

A Brave key is still the best option, and image search still needs Brave or SearXNG.

### Web Search settings in the dashboard

A new **Web Search** page under **Connect** sets up search without editing `config.toml`.

- **Pick a provider from four cards:** the free sources, Brave Search API, your own SearXNG, or a custom endpoint. The page shows which one your agents use now.
- **Step-by-step setup on the page:** where to get a Brave key, the Docker snippet for SearXNG, and the two SearXNG settings a fresh instance gets wrong.
- **Paste a key, or pick one from Secrets.** A pasted key is saved to Secrets automatically; only its name goes into the config.
- **Test before you save.** It runs a real search with what the form holds and shows the first results, or the reason it failed.
- **Restart from the page.** Changes apply after a restart, and the page offers one.

### Upgrading

- **Docker:** `docker compose pull && docker compose up -d`
- **Binary:** `nouride update`

No configuration changes.
