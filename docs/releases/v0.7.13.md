### Models

- **A turn is budgeted by the context window its gateway states for the model.** A model the built-in table of families did not know was budgeted at 32k whatever it really takes: its history was cut and its tool output trimmed every round. An endpoint whose `/models` listing states a window — Nougate's `context_window`, OpenRouter's `context_length`, vLLM's `max_model_len` — is now believed, after the pack's own `[llm] context_window` and before the table. The listing is asked when the daemon is ready and at most hourly; no turn waits for it, so the first turn after a start budgets by the table and the next by the gateway.
- **`nouride doctor` and the agent's Model tab say the window an agent is budgeted at, and where it comes from** — the pack, the gateway, the table, or a guess. A guess is a warning, with the two fixes.
- **An agent's `fallback_model` answers when its own model cannot.** Set it in the pack's `[llm]` or on the agent's Model tab: a model on the same profile, asked once the agent's model has spent its retries on a rate limit or an overloaded provider, or is not served at all — and kept for the rest of that turn. A gateway like Nougate already fails over between the providers of one model; another model is the one failover it cannot make. A model that is not served is also told to the operator, since the fallback would otherwise hide it. A credential, a balance or a refused request is not retried on the fallback.

### MCP

- **Nouride speaks MCP 2025-06-18.** It asks for it when it connects, and speaks 2025-03-26 or 2024-11-05 with a server that answers one of those. A server that answers anything else is refused: the log names the server and both versions, and its tools are not offered. Over HTTP, every request after the handshake names the version.
- **A server whose tools change while it runs is heard.** When a server declared it would say so, its tools are listed again — once for a burst of changes — and the next turn has them; the log says what was added and removed. A turn already running keeps the tools it started with. Over Streamable HTTP this holds a stream open to that server, and only to a server that declared it.
- **A call that does not fit a tool's schema is not sent.** A missing required argument, or one of the wrong type, goes back to the model with what to fix, before anyone is asked to approve it. A number, a boolean or an object a model sends as its text — `"5"`, `"true"` — is taken as what the schema declares, as a lenient server would.
- **Structured results and resource links are read.** A result that carries only structured data reaches the model as JSON, and a link to a resource is a line with its address.
- **A server that forgot the session is reconnected.** After a server restarted, every call failed until Nouride restarted too; now the first call fails and the server is reconnected a second later.
- **Nouride's own MCP server** answers in the version a client asks for when it speaks it, and in 2025-06-18 otherwise, and refuses a request that names a version it does not speak.

### The bundled LLM gateway

- **The router editions' gateway states a model's context window in `/models`** where the route knows it: Kiro's catalogue, and a custom provider's upstream listing (`context_length`, `max_model_len` …) — filled in when a sync finds it, and editable in its Models table. Nothing is guessed: a route that does not know says nothing, and Nouride uses its table.

### Upgrading

- **Docker:** `docker compose pull && docker compose up -d`. Check the configuration with the new image first: `docker run --rm -v ./.nouride:/app/.nouride ghcr.io/nouverse/nouride:0.7.13 nouride config check`.
- **Binary:** `nouride update --start`.
- **Before you upgrade:** an MCP server answering a protocol version other than these three is no longer connected — `nouride mcp` and the log name it. There is no migration in this release.
