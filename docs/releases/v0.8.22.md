**0.8.22 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

On Docker, check your configuration with the new image before you switch:
`docker run --rm -v ./nouride:/app/.nouride ghcr.io/nouverse/nouride:0.8.22 nouride config check`, with the volume your
compose file mounts.

### Nouride on an Android phone

- **Nouride Home, an app that makes an Android phone the home of Nouride.** Install it, press Start, and the phone runs
  Nouride, the Router edition with its LLM gateway, reachable from the phone itself and from other devices on the same
  Wi-Fi. It sets everything up on the first start, with its progress on the screen, keeps Nouride running with the
  screen off, opens the dashboard already signed in, and updates itself. For arm64 phones; the APK is on
  [its releases page](https://github.com/nouverse/nouride-android-appliance/releases).

### The dashboard on a phone

- **Menus stay inside the screen.** Every dropdown, such as a model or a connection to pick, opens where it fits, above
  its button when there is no room below, and closes when its button scrolls away. On a phone some opened half off
  the screen.
- **Picking a model no longer jumps around.** A model field starts empty and suggests models as you type; on a phone
  its list opened before the keyboard came up and moved with every keystroke. In setup, the first model on the list
  is no longer chosen for you.
- **The Overview's office fits a phone** instead of spilling over the cards below it.
- **The sign-in, welcome and setup pages no longer slide sideways** on a phone.
- **A new install goes straight to the setup wizard,** without the Overview showing for a moment first.
- **Inside Nouride Home, the header has a way back to the app.**

### Fixes

- **A mission's question shows buttons only for the answers the agent offers.** Since 0.8.12, numbered lines in a
  question were read as answers to pick from, so an agent that listed steps to follow above its question got a button
  per step, and a tap answered the question with a step. Now an agent names the answers itself, two to six, and each
  gets a button; they are also listed under the question, so a chat without buttons and the dashboard show them. A
  button from before this update says to answer in words when pressed.
- **An agent looking back over its work to improve a skill reads every file the skill keeps.** A support file whose name
  was not all lowercase, such as `references/INFRASTRUCTURE.md`, was shown to it but refused when it asked to read it,
  and it spent its rounds asking again.
- **A project skill that is a link loads.** A skill in a project's `.agents/skills/` that links to a folder elsewhere
  in the same project, such as a private submodule's, was skipped; an agent now sees it and can read it. A link that
  leads out of the project is still skipped.
- **An agent set to work on a project looks for the project's own skills.** When a project has `.agents/skills/` and is
  not one of the agent's `skill_roots`, the agent reads the skills that fit the task as the project's conventions and
  asks you whether to add the project to its `skill_roots`, which only you can change.
- **PDFs in the knowledge base.** An agent asked to keep a PDF or an Office file now knows it is read for its text, and
  hands over the file itself instead of offering to take the text out first. A scanned PDF, which has no text in it, was
  counted as read with nothing in it, and the agent that kept it was told it could be searched; it is now kept and shown
  as not searched, with the reason, as a picture is.

### The bundled LLM gateway

- **Antigravity answers again.** Google stopped serving the client version the gateway reported, and every reply was
  "This version of Antigravity is no longer supported". It now reports the current one.
- **Gemini 3.8 Flash comes as Low, Medium and High,** `gemini-3.8-flash-low`, `-medium` and `-high`, as Google now
  serves them. `gemini-3.8-flash` keeps working and is Medium.
- **Claude Sonnet 5.5 and Claude Opus 5.5, each Low, Medium and High,** for the accounts Google has moved to them,
  for example `claude-sonnet-5-5-medium`. Google moves accounts one by one; an account still on 4.6 does not have them.
- **Also offered:** Gemini 3 Flash, Gemini 3.5 Flash Lite and Gemini 2.5 Pro.
