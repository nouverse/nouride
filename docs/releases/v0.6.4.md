### Long conversations stay sharp

Compaction has been rebuilt so an agent keeps more of what was said and stops rewriting its own notes.

- **Old tool output goes first.** Before anything is summarized, large tool results from earlier turns are cut down. Often that alone is enough, and no model call is needed.
- **Summarized once, never again.** Each compaction adds a new part to the notes. Earlier parts are kept as they were instead of being summarized again, so details no longer blur away a little more each time.
- **Nothing is lost.** When the notes grow too long, the oldest parts are archived to a one-line index. The agent can read back the exact exchanges behind any archived part with `memory_read`.
- **Compaction happens after the reply.** It runs once the agent has answered, so you no longer wait for it in the middle of a message.
- **The size is measured, not guessed.** The trigger uses the tokens the provider actually billed for the last request, so dense text like logs no longer slips past the limit.
- **Limits per model and per agent.** Gemini Flash models compact at 200k tokens and other models at 160k. Override with `compact_at_tokens` in `[llm.context]` of `config.toml`, or in an agent's own `[llm]`.
- **`compact_at_tokens` now counts the whole request**: system prompt, tools and history. Before, it counted history only. If you set it yourself, the same number now compacts about 50k tokens earlier. Raise it, or remove it to use the per-model default.
- **The summaries are structured.** Every part records the goal, constraints and preferences, what was done, what is still open, decisions, failed attempts, and exact values like ids, ports and paths.
- After three failures in a row, compaction pauses for 30 minutes instead of retrying on every message.

### Fixes

- **Scheduled `--command` jobs get the agent's `exec_secrets`.** A job that needed a token, like a PyPI upload, failed with the variable missing. The secrets are masked in the job's output.
- **Agents no longer open old attachments on their own.** After a new conversation started, files from the previous one could still look current, and agents read them unasked. They are now listed separately as files from earlier conversations, and opened only when you refer to them.

### For developers

- `nouride chat` accepts `/attach <path> [text]` to send a file from the terminal.
