**0.8.24 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

On Docker, check your configuration with the new image before you switch:
`docker run --rm -v ./nouride:/app/.nouride ghcr.io/nouverse/nouride:0.8.24 nouride config check`, with the volume your
compose file mounts.

### A new look for the dashboard

- **Soft and a little playful, carried by the Nouride cat.** A cream day and a violet-grey night, peach for the main
  action, lavender for where you are, mint for what is moving, pink for what needs you. Headings are set in Fredoka.
  The cat greets you on Home, sleeps on an empty page, gives a thumbs up when something is saved, and looks puzzled on
  a page that is not there. Each agent keeps its own pixel cat.
- **The menu, by how often you open a page.** Home, Chats, Work and Agents every day; Skills, Connectors and Memory now
  and then; everything you set up once behind Settings. Work holds what agents do on their own: what waits for your
  answer, missions, helpers, the schedule and webhooks. Agents holds the Office. Memory holds people and groups.
  Overview is now Home, System Logs is Logs, and Background Helpers is Helpers.
- **Home is an inbox.** It says what needs you and lets you answer a tool call right there; a mission's question, a
  request to talk to your agents, a skill, a fact or a document to review are each a card that opens where it is
  decided. Below that, what is moving with its checklist, a quick line to an agent, and your agents beside the Office.
  When nothing waits, the cat naps.
- **One count of what needs you,** in Home's greeting, on the menu where each thing is answered, and in the browser
  tab's title, so a tab in the background still tells you.
- **Settings is a page** of grouped cards with a search box, and each of its pages has a way back to it.
- **Your box** sits at the foot of the menu: whether it is running well, its version, and an update when one is ready.
- **On a phone, a tab bar** at the bottom (Home, Chats, Work, Agents, More) replaces the side menu, with a floating
  "+ Chat" on Home.
- **Sign-in, the first visit and setup** have the new look too, and the dashboard has its own icon in your browser's
  tab, apart from the site's.

### Motion

- **The dashboard moves where something changes, and only there:** a page fades in, a new message or document eases
  in, dialogs and toasts open and close, a card that changed lights up for a moment, and a list still loading shows its
  shape. On a phone the menu slides up and down, and the mark on the page you are on moves to the one you open. All of
  it stops when your system asks for less motion.

### Coding CLIs, kept up to date

- **Where each CLI stands, in plain words,** on the Models page and on the Brain tab of an agent that works in one:
  up to date, a newer version is out, newer than this Nouride was tested with (it runs, with a warning), or older than
  it supports. `nouride agents scan` and `nouride doctor` say the same.
- **Update, and the way back.** The button beside a CLI that is behind asks your orchestrator, in a chat message you
  send, to run `nouride agents update <cli>`: it
  waits until no turn runs in that CLI, installs the version, starts it again and checks that it still has what
  Nouride uses. A version that fails the check leaves only that CLI's agents unavailable, says why, and offers the
  version before. The CLIs' own updaters stay off.
- This release is tested with Claude Code's adapter 0.95.0 to 0.100.0 and Codex's 2.3.0 to 2.5.0.

### Skills

- **An agent's project folders, without editing its config.** The agent's Skills page lists each folder it takes
  skills from, with the skills it brings, and an admin adds or removes one there. `nouride agent skill-root` does the
  same, and an agent can ask for one, which you approve.
- **Explore's search results run down the page,** where they were held in a box one result tall.

### Installing

- **A download that failed says so.** When GitHub fails for a moment while the installer fetches a release's checksum
  file, it now names what went wrong and asks you to run the same command again, where it said the release had no
  checksum file at all. A release that truly has none is still refused.

### The website

- **nouride.com has the new look,** with a new front page and the docs in the same soft colours, light and dark.
