**0.8.27 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

On Docker, check your configuration with the new image before you switch:
`docker run --rm -v ./nouride:/app/.nouride ghcr.io/nouverse/nouride:0.8.27 nouride config check`, with the volume your
compose file mounts.

### Fixes

- **An update download that stops moving is picked up again instead of waiting forever.** A connection that went
  quiet without closing left the download at the same number of bytes for good, and pressing Update again changed
  nothing. Now a download that receives nothing for 30 seconds is cut and continued from where it was, a few times,
  before it says plainly that it failed.
