### Updating

- **A bridge release.** Its first start rewrites older settings and data where they are stored, with a backup and one log line per change. Nothing changes in what your agents can do.
  - In each agent's pack: the list form of `exec_secrets` becomes the table with every secret bound to `"*"`, which is the same access the list gave. `memory_recent` and `task_plan` become `memory_search` and `plan`, in a pack's enabled tools, its `approval_required` and its `blocked`. `Role:` in `IDENTITY.md` becomes `Headline:`. A pack's own `[[mcp_servers]]` moves to `agents/mcp.toml`, as before.
  - In `config.toml`: a Telegram connection's `mode = "webhook"` is removed, so it polls, the default. `[alerts] gateway = "local:dev"` is removed; it reached nothing, and the start now warns that alerts have nowhere to go.
  - In the data: memory search's older vector keys, older approvals, and conversation summaries from before 0.7.6 are moved to today's shape. WhatsApp session files in the old format are cleared when WhatsApp starts, and a Nouride Box's own settings are moved too.
- **If something cannot be rewritten**, for example a file the daemon cannot write, the start says so and `nouride doctor` names it. Fix it and restart.
- **Bind your secrets to their commands.** A secret bound to `"*"` reaches every command an agent runs. Each one can be bound to the commands that need it, for example `github_token = ["gh", "git"]`, in the agent's `config.toml`. See *Approvals* in the docs.
