### Approvals

- **The three levels are called careful, balanced and trusted.** They were `normal`, `risky` and `none`; what each one asks is unchanged. The dashboard, `/approvals careful|balanced` in chat and the docs use the new names, and the old words are refused there with the new one named. `per-person` stays as it is. `trusted` is still set only in the dashboard or the config file, never from chat.

### Chat

- **Groups say who said what.** Every line an agent reads in a group, the message it was tagged in too, is written `Name: …`. Someone in `[[people]]` is called by that name on every account they write from; anyone else by the name their platform shows. An agent no longer mistakes the person asking for whoever spoke just before them. Every platform, the dashboard's rooms included.
- **What a group said before you tagged the agent is background.** The agent no longer brings any of it up unless you ask about it.
- **Send a message to another chat.** Ask an agent "send this to the family group" and it uses `send_message`: a person's name, a group's name or a chat's address, among the chats it can reach through its own connections. It asks first, at the agent's approval level. What it sent becomes part of that chat's conversation, so when someone there answers, the agent knows what it said. A message a scheduled job posts is kept the same way.

### Secrets

- **A secret kept from chat reaches the agent's commands at once.** `/secret set` or an agent's `secret_save` also adds `<name> = ["*"]` under `[security.exec_secrets]` in that agent's `config.toml`, so nobody has to edit the pack. Narrow the line to the commands that need it; a name already bound there is left as it is.

### Updating

- **A bridge release.** Its first start rewrites `approvals = "normal"`, `"risky"` and `"none"` to `"careful"`, `"balanced"` and `"trusted"` in `config.toml` and in every agent's pack, with a backup and one log line per change. If a file cannot be rewritten, the start says so and `nouride doctor` names it; the old word still works until it is fixed. **Nothing to do but keep updating.**
