**0.8.26 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

On Docker, check your configuration with the new image before you switch:
`docker run --rm -v ./nouride:/app/.nouride ghcr.io/nouverse/nouride:0.8.26 nouride config check`, with the volume your
compose file mounts.

### Fixes

- **Putting every agent to sleep no longer sends the dashboard back to setup.** With all of them asleep for the night,
  every page opened the setup wizard as if no agent had been made; nothing was lost, and they are counted again now.
- **The installer tries a dropped download again and picks up where it stopped**, instead of failing the install. A
  first start of Nouride Home on a phone's Wi-Fi lost the download midway and stopped there; the checksum file and
  its signature are tried again too, and a download that still fails names its address and what went wrong.
- **An update rides out a moment's trouble at GitHub.** When the download had finished and GitHub answered an error for
  a few seconds while the update was checked, the install stopped with "Try again in a moment"; it now tries again on its
  own, a few times, before it says so.
