### Long work

- **A long piece of work is checked on, not left to run.** At 5, 10, 20, 40 minutes and so on, an agent working for another — a helper, or one asked with `ask_agent` — is told to stop and report honestly if it is stuck, and the agent that asked is told how long it has been, so it can wait, tell you, or stop it. Nothing is stopped for it. A reply you are waiting on is asked for a one-line status on the same schedule. `[agents] nudge_after_minutes` sets the first step; `0` turns it off.
- **A brief that changes something asks for that change only.** Agents are told to keep research in its own read-only brief, and to say in every brief when to stop and report.
- **Tool output cleared from a long conversation is kept, not lost.** When a conversation runs out of room, an earlier tool result moves to a file and the conversation says where, so the agent reads it back instead of running the command again.

### Model replies

- **A reply may be as long as the model allows.** The cap on one reply is the model's own — 32,000 tokens for current Claude, Gemini and GPT-5 models — instead of a flat 8,192, so a long document is no longer cut off in the middle of being written. A number you set in `[llm] max_tokens` still wins.
- **A reply cut at the limit says so.** The agent is told its reply was cut at the output limit and to send big content in parts, and `write` takes `append: true` so a large file goes out a part at a time.
- **When a helper model is unavailable, the agent's own model steps in.** Summarising a long conversation and the nightly memory pass fall back to the agent's own model when the model set for them cannot answer, and `nouride doctor` says when either has been failing.

### Credentials

- **A credential a command prints is held, not shown.** When a command prints a `.env`, a credentials file, a private key or an environment dump — on this machine or another one over `ssh` — each value becomes a `$TMP_SECRET_…` handle for the conversation: the agent still uses it in a command and never sees it. Keys, comments, numbers and words like `production` stay readable.

### Chat

- **Context upkeep stays out of the chat.** Compacting a conversation, clearing old tool output and keeping big output in a file still happen; the progress line no longer reports them.
- The `nouride` tool's output reaches the agent without terminal colour codes.
- A `nouride` command whose request runs out of time — a long `nouride memory pass` — says the daemon may still be working on it, not that it cannot be reached.
