**0.8.5 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

### Changed

- **Long work goes to a mission.** An agent asked for work that will take more than about ten minutes — a refactor
  across many files, many steps or items, research ending in a report — starts a mission for it and says so, rather
  than working it in the chat. Before, only work left running while you were away read as a mission's. Agents answered
  by Claude Code or Codex are told the same.

### Agents answered by Claude Code or Codex

- **You see the work as it happens.** What the agent writes between its steps reaches the chat as it writes it, each
  its own message, the way its own terminal shows it. Before, all of it came at the end, in one long message, minutes
  later. Each time it speaks, the progress line so far closes on `✓ 3 steps · 20s`, and the next steps start a new one
  below.
- **Typing stays on while it works.** It went out five seconds into every reply.
- **The progress line names each command** — `git status`, with 💻 for a command, 📖 for a file read, ✏️ for an edit,
  🔍 for a search — where every step read "🔧 Terminal" and the line looked stuck.
- **A progress line no longer stays at ⏳ under the answer.** With a fast agent, the line for its last steps could
  arrive after the answer and never close.
- **A message you send while it works gets its own answer,** before it goes on to the next. Both answers came as one.
- **It knows who it is talking to.** In a direct chat it was not told who you are. It is told the person from People
  and what it remembers about them, as every other agent is.
- Its persona files reach it each under a heading of its own, so a file that does not start with one is no longer read
  as the end of the one before it.
