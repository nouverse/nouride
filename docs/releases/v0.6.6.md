### Memory as a graph

Memory has a new **Graph view**, next to its tabs. It shows every conversation your agents remember as a dot. Each dot is joined to the people in it, its tags, the agent it was with, and the conversations the nightly pass found related. You can see who comes up together and which subjects keep coming back.

- **Click a dot** to see what it links to. Open a conversation from the side panel, or show only one person, tag or agent. Drag a dot to move it.
- **Filter** by agents, people, tags and time range. Tick as many of each as you like: several agents show conversations with any of them, and an agent with a tag shows conversations that have both. Each choice shows how many conversations it has. The filter is kept in the address, so you can reload or share a view.
- **Find** a person, tag or conversation by name with the search box.
- **Show or hide** people, tags and agents from the legend.

It stays light on a small box:

- **The daemon sends only ids and one-line labels, gzipped.** The 300 newest conversations are about 30 KB. You can show up to 1,000.
- **It is built once, then kept until memory changes.** In practice that is once a night, after the pass.
- **Your browser does the layout, and stops once it settles.** The graph code, about 28 KB, loads only when you open the page.
- **Tags that only one shown conversation has are left out.** On a real vault that is most of them, and they connect nothing.

### Upgrading

- **Docker:** `docker compose pull && docker compose up -d`
- **Binary:** `nouride update`
