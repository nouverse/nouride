**0.8.31 updates from 0.8.0 or later.** From 0.7.x, start 0.8.0 once first:
[Upgrading to 0.8](https://nouride.com/en/docs/deployment/upgrading-to-0-8/) has the way across.

On Docker, check your configuration with the new image before you switch:
`docker run --rm -v ./nouride:/app/.nouride ghcr.io/nouverse/nouride:0.8.31 nouride config check`, with the volume your
compose file mounts.

### Fixes

- **On a phone's browser, the dashboard is as tall as the screen you see.** It was as tall as the screen with the
  browser's toolbar put away, so the foot of a page sat under the tab bar: the Chats list could not be scrolled to its
  last rows, and a tap on a tab sometimes did nothing, because the browser took it to bring its toolbar back. A tall
  dialog ends above the toolbar for the same reason.
- **A message that pops up at the foot of a phone's screen stands above the tab bar**, where it lay over Agents and
  More and took their taps while it showed.
- **A build made from the source carries the built-in skills as they are in the repository**, without the cache files
  Python leaves beside a skill's scripts. Released builds never had them.

### Changes

- **The `nouride` commands work as before.** The code behind the ones that ask a running Nouride (`status`, `chat`,
  `agents` and the rest) now lives in a part of its own, apart from the daemon's, so a change to one cannot reach into
  the other. Every command, its options, what it prints and its exit codes are the same, and Nouride is still one
  program of the same size.
